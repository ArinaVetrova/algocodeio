## Version 1 – однопоточный xmlEncryptor (`xmlEncryptor.h`)

1. **Добавлена вспомогательная структура NodeEncyptionCollector**
   Хранит данные для шифрования XML-узла.
   - `shared_ptr<XmlNode> node`: указатель на узел XML, содержащий тег, содержимое узли и вектор его прямых потомков
   - `path`: путь до узла в виде вектора строковых представлений (теги от родительского к текущему)
   - `text`: текстовое содержимое узла.
   - `children`: вектор пар (имя дочернего узла и его зашифрованный текст).

3. **реализация функции `encryptNode` в целях тестирования**
   По условиям задания функция реализована снаружи и ее реализовывать не надо, реализована как создания строки в порядке шифрования для упрощения тестирования

4. **Реализация функции `encryptXmlTree`**
   Алгоритм построен на итеративном обходе дерева XML с помощью std::stack.
   Для каждого посещаемого узла в stack помещается объект NodeEncyptionCollector, в котором сохраняется путь, ссылка на узел, счётчик уже обработанных детей, контейнер для зашифрованных детей и коллбек-функция, которая будет вызвана, когда узел будет зашифрован с помощью `encryptNode`, чтобы расположить результат в EncryptedChildren родительского узла.

   Пока processedChilds меньше количества детей текущего узла, берём следующий дочерний узел, формируем для него новый путь (добавляем имя дочернего тега) и помещаем новый NodeEncyptionCollector в stack.
   
   Когда у узла нет необработанных детей, вызываем encryptNode с текущим путем, текстом узла и уже собранным списком encryptedChilds. Полученную строку и тег текущего узнал передаем в заранее созданный коллбек текущего узла. Коллбек сохраняет результат в encryptedChilds соответсующего родителя. Обработанный узел удаляется из stack
   Когда stack становится пустым, обработан корневой узел, а res содержит зашифрованное представление всего дерева и возвращается вызывающему коду.

5. **Тесты**: testXmlEncryptor.cpp
