## Version 1 – исправленный LRU (`TLruCache.cpp`)

1. **Класс сделан шаблонным**
   Класс теперь является шаблоном и принимает типы `Key` и `Val`.

2. **Исходная структура с 2мя unordered_map и set заменена на unordered_map + list**
   - `std::unordered_map<Key, typename std::list<Node>::iterator> Data` хранит маппинг ключа итератор в CacheList
   - `std::list<Node> CacheList` хранит пары ключ-значение

   > Это классическое решение использует `unordered_map` для быстрого поиска по ключу и `list` для хранения позиции в очереди на удаление, все операции выполняются за `O(1)`.
   > Для вытеснения используется последний элемент в CacheList
   > Для обновления недавности использования пара помещается в начало CacheList

3. **Move-семантика в `Set`**
   Значение принимается как rvalue для предотвращения лишнего копирования тяжелых объектов.

7. **Возврат указателя в `TryGet`**
   Возвращается указатель на значение, чтобы избежать копирования тяжелых объектов.  
   Возвращает `nullptr`, если ключ не найден.  
   Для безопасного использования указателя даже при возможном rehash вызывается `Data.reserve(SizeLimit)` в конструкторе.

8. **Исключения убраны**
   Вместо выброса исключений методы возвращают `false` или `nullptr` при неудаче, что делает API безопаснее и предсказуемее.

9. **Тесты**: testLruCache.cpp

## Версия 2 – LFU Cache (`TLfuCache.cpp`)

Шаблонный LFU (Least Frequently Used) кэш с LRU-порядком внутри одинаковой частоты.

1. **Структуры данных**

- `KeyMap` — `unordered_map<Key, Node>`: хранит ключи, значения и итераторы.
- `FreqBuckets` — `unordered_map<Frequency, list<Key>>`: хранит ключи по частотам с порядком LRU внутри каждой частоты.
- `Node` — содержит `shared_ptr<Val> value`, `freq` и `list`-итератор.

2. **Основные возможности**
- Шаблонный класс: поддерживает любые типы ключей и значений.
- Move-семантика в `Set` для предотвращения лишнего копирования.
- Операции доступа, вставки и обновления частоты выполняются за `O(1)` в среднем.
- Eviction:
  - Вытеснение ключа с минимальной частотой (`LFU`)
  - Если несколько ключей с одинаковой частотой, вытесняется наименее недавно использованный (`LRU` внутри частоты)
- Возврат значения через `shared_ptr` (`TryGet`) для безопасного использования без копирования.

3. **Вспомогательные приватные функции**

- `UpdateFrequency(const Key&)` — обновляет частоту использования ключа и перемещает его в нужный `FreqBucket`.
- `EvictLFU()` — вытесняет ключ с минимальной частотой и наименее недавно использованный внутри этой частоты.
- `UpdateMinFreq()` — пересчитывает текущую минимальную частоту, если старый `FreqBucket` опустел.

9. **Тесты**: testLfuCache.cpp

## Версия 3 – Thread-safe LFU Cache с ленивым обновлением частоты (`TLfuCacheThreadsafeLazyUpdate.cpp`)

Шаблонный LFU кэш с поддержкой многопоточности и ленивого обновления частоты для уменьшения блокировок при чтении.

1. **Структуры данных**

- `KeyMap` — `unordered_map<Key, Node>`: хранит ключи, значения, частоту и счётчик обращений (`readCounter`).
- `FreqBuckets` — `unordered_map<Frequency, list<Key>>`: хранит ключи по частотам с порядком LRU внутри каждой частоты.
- `Node` — содержит `shared_ptr<Val> value`, `freq`, атомарный `readCounter` и `list`-итератор.

2. **Основные изменения по сравнению с TLfuCache**

- Добавлен `std::shared_mutex mtx` для безопасного доступа из нескольких потоков.
- Каждое чтение через `TryGet` увеличивает `readCounter` вместо мгновенного обновления частоты.
- Частота обновляется лениво: только после того, как `readCounter >= LazyUpdateThreshold`, чтобы снизить количество блокировок записи.
- Move-семантика и `shared_ptr` сохранены для эффективной работы с тяжёлыми объектами.
- `Set`, `Erase` и `Exist` теперь защищены mutex-ами.

3. **Ленивое обновление частоты**

- `readCounter` хранится атомарно для каждого `Node`.
- Частота увеличивается только после достижения порога `LazyUpdateThreshold`.
- При обновлении частоты используется уникальная блокировка, чтобы корректно переместить ключ между `FreqBuckets`.

4. **Вспомогательные приватные функции**

- `UpdateFrequency(const Key&)` — обновляет частоту использования ключа и перемещает его в нужный `FreqBucket`.
- `EvictLFU()` — вытесняет ключ с минимальной частотой и наименее недавно использованный внутри этой частоты.
- `UpdateMinFreq()` — пересчитывает текущую минимальную частоту, если старый `FreqBucket` опустел.

6. **Тесты**: `testLfuCacheThreadsafeLazyUpdate.h`

## Версия 4 – Потокобезопасный LFU c Lock stripping (`TLfuCacheLockStripping.cpp`)

Шаблонный LFU кэш с разделением на шарды (lock striping) для повышения параллелизма и уменьшения блокировок.

1. **Структуры данных**

- `Shard` — отдельный шард с `KeyMap`, `FreqBuckets`, минимальной частотой и `shared_mutex`.
- `KeyMap` — `unordered_map<Key, Node>`: хранит ключи, значения и итераторы внутри шарда.
- `FreqBuckets` — `unordered_map<Frequency, list<Key>>`: хранит ключи по частотам с LRU-порядком внутри каждой частоты.
- `Node` — содержит `shared_ptr<Val> value`, `freq` и `list`-итератор.

2. **Основные изменения по сравнению с TLfuCache**

- Вся структура разбита на `NumShards` отдельных блоков с собственными mutex-ами.
- Доступ к ключу идёт через вычисление шарда `hash(key) % NumShards`.
- Это позволяет параллельно читать и писать в разные шарды без блокировки всего кэша.
- Move-семантика и `shared_ptr` сохранены для эффективной работы с тяжёлыми объектами.
- **Важно:** лимит размера каждого шарда вычисляется как `sizeLimit / NumShards`.  
  В результате суммарный лимит всех шардов может быть меньше ожидаемого `sizeLimit` из-за целочисленного деления.

3. **Eviction и частоты**

- Частота обновляется сразу при `Set` и `TryGet`, аналогично TLfuCache, но только внутри шарда.
- Eviction (`EvictLFU`) выполняется локально на уровне шарда.
- Если несколько ключей с одинаковой частотой, вытесняется наименее недавно использованный (`LRU внутри частоты`).

4. **Вспомогательные приватные функции**

- `UpdateFrequency(Shard&, const Key&)` — обновляет частоту ключа внутри шарда.
- `EvictLFU(Shard&)` — вытесняет ключ с минимальной частотой внутри шарда.
- `UpdateMinFreq(Shard&)` — пересчитывает минимальную частоту в шарде после удаления.

5. **Тесты**:  `testLfuCacheLockStripping.cpp`
