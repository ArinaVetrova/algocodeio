# CallbackScheduler - `callbackScheduler.cpp`

1. **Отдельный рабочий поток**  
   Запускается один `std::thread`, который обрабатывает запланированные колбеки.

2. **Хранение задач по времени**  
   Используется `std::multimap<TimePoint, Callback>`, элементы отсортированы по ближайшему TimePoint,  получение ближайшего колбека через `begin()`.

3. **Ожидание через condition_variable**  
   Поток спит до времени ближайшего колбека через `wait_until`, также `Schedule` может разбудить поток его при добавлении более ранней задачи.

4. **Отмена колбека через handle**  
   `Schedule` возвращает `shared_ptr<Callback>`.  
   Отмена выполняется установкой `atomic<bool> cancelled` без удаления из контейнера.

5. **Ленивая очистка отменённых задач**  
   Отменённые колбеки удаляются при наступлении их времени выполнения.

6. **Выполнение вне блокировки**  
   Колбек вызывается после освобождения `mutex`, чтобы не блокировать планирование новых задач.

7. **Корректное завершение**  
   В деструкторе выставляется `stop`, поток пробуждается через `notify_one` и `join`.
